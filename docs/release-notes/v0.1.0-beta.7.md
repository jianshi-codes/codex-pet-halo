# Pet Halo 0.1.0 Beta 7

Pet Halo is an independent, unofficial macOS companion for Codex. Beta 7
repairs the unsigned distribution bundle so macOS Accessibility can associate a
complete application identity after the user explicitly grants access.

## Highlights

- Applies a complete ad-hoc signature to the embedded framework and application
  after final binary stripping, while preserving Hardened Runtime.
- Disables Library Validation only for the unsigned preview App so its ad-hoc
  embedded framework can load without a shared Developer ID Team ID; other
  Hardened Runtime protections remain enabled.
- Requires strict bundle verification for unsigned previews and rejects both a
  missing bundle seal and an unexpected Developer ID identity.
- Launches the packaged application through macOS LaunchServices during release
  validation instead of bypassing the bundle through its executable path.
- Runs packaged launch and owned-child shutdown checks in both validation-only
  and unsigned publication workflows.

## Compatibility boundary

This release changes packaging and release validation only. Pet discovery,
Accessibility field access, target selection, Ring geometry, Usage semantics,
and the Pet/window/free-floating fallback hierarchy are unchanged from Beta 6.

The ad-hoc signature gives each exact build a complete macOS code requirement,
but it is not an Apple-trusted identity. A later build can have a different code
requirement, so users may need to remove and re-add Pet Halo in Accessibility
after updating.

## Requirements

- macOS 14.0 or later on Apple silicon or Intel.
- Supported Codex CLI and Desktop versions listed in `docs/COMPATIBILITY.md`.
- Accessibility permission only when following is enabled.

## Distribution boundary

This is Beta software distributed as an **Unsigned Developer Preview**. The
ad-hoc bundle signature protects bundle integrity and enables a complete local
code identity, but it is not a Developer ID signature and is not notarized by
Apple. macOS may still block the first launch.

Verify `SHA256SUMS`, the GitHub source, and repository provenance before using
Finder **Open** or **Open Anyway**. After moving the exact App to Applications,
grant Accessibility access to that copy. Do not disable Gatekeeper globally.

`Pet-Halo-0.1.0-beta.7-unsigned-universal.zip` remains an unsigned distribution.
A future Developer ID-signed and notarized artifact must use a new tag and build
number; it must not replace this release.
