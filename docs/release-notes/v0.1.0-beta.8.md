# Pet Halo 0.1.0 Beta 8

Pet Halo is an independent, unofficial macOS companion for Codex. Beta 8 fixes
Usage showing `N/A` when a current Codex or ChatGPT application contains its
CLI in the newer nested bundle layout and Pet Halo is launched from Finder or
Spotlight without a shell-provided CLI path.

## Highlights

- Finds the nested `codex-cli/CodexCLI.app/Contents/MacOS/codex` executable in
  Codex.app and ChatGPT.app under Applications.
- Preserves the priority of inherited absolute `PATH` entries, standard
  Homebrew prefixes, and legacy application resource paths.
- Retains symlink resolution, executable-file validation, bounded version
  inspection, and the existing fail-closed protocol compatibility policy.

## Compatibility boundary

This release changes executable discovery only. Account and rate-limit
requests, Usage semantics, authentication behavior, Pet discovery and
following, Ring presentation, and release packaging are unchanged from Beta 7.
Newer pre-1.0 CLI versions still require successful provisional runtime
validation; discovery does not add a version to the reviewed registry.

## Requirements

- macOS 14.0 or later on Apple silicon or Intel.
- A compatible, signed-in Codex CLI, installed separately or bundled with
  Codex.app or ChatGPT.app in Applications.
- Accessibility permission only when following is enabled.

## Distribution boundary

This is an **Unsigned Developer Preview**, distributed as
`Pet-Halo-0.1.0-beta.8-unsigned-universal.zip`. It has complete ad-hoc App and
framework signatures with Hardened Runtime, but is not Developer ID-signed
and not notarized by Apple. macOS may block first launch. Verify `SHA256SUMS`,
the source, and repository provenance before using Finder **Open** or
**Open Anyway**; do not disable Gatekeeper globally.

The ad-hoc requirement can change between builds, so an update may require
removing and re-adding Pet Halo in Accessibility. Independent clean-machine
acceptance is recorded separately from local launch and Usage evidence. A
future signed and notarized artifact must use a new tag and build number.
