# Pet Halo 0.1.0 Beta 9

## Changes

- Locate Pet once at startup and keep the ring fixed. After moving Pet, choose
  **Locate Pet** from the menu to align it again. Failed or ambiguous requests
  preserve the previous position. There is no automatic reacquisition on
  hide/wake, Quick Chat, or display changes.
- Handle current Codex Desktop's transparent full-display Pet overlay with one
  ScreenCaptureKit single-window image per request. Local alpha-component
  detection requires one plausible body; no OCR or text inspection is used.
- Remove automatic-following switches, Codex-window fallback calibration,
  ring-center adjustment, and debug orientation controls from the menu.
  Usage refresh and Show/Hide remain available.

## Permissions and privacy

Allow Pet Halo in macOS Privacy & Security → Screen Recording (Screen & System
Audio Recording on newer macOS). Accessibility permission is not needed for
this positioning path. Make Pet visible before launch or choose Locate Pet later.
The capture includes only the selected Codex Pet overlay, which may contain Pet
status or Quick Chat pixels. Images stay in memory and are released after
processing. No full-display fallback, cursor/audio capture, saved images,
continuous recording, polling, mouse observer, or network telemetry is added.

## Evidence and limitations

The user confirmed fixed placement after dragging and successful manual
relocation on Codex Desktop 26.1007.30912 (20156). A local 30-second Debug idle
observation averaged approximately 0.10% of one CPU core and 19.7 MiB physical
footprint, compared with approximately 18% CPU for the discarded adaptive
capture trial. This is a short local observation, not a universal benchmark or
battery-life promise. Artwork, pose, scale, multiple overlays and every Quick
Chat layout are not exhaustively validated. Opaque or ambiguous captures fail
closed. No Usage semantics or reviewed CLI registry entry changes.

## Distribution

**Unsigned Developer Preview:** `Pet-Halo-0.1.0-beta.9-unsigned-universal.zip`
contains a Universal macOS 14+ application with complete ad-hoc signatures and
Hardened Runtime. It is not Developer ID-signed and not notarized by Apple.
Gatekeeper may block launch; check source provenance and SHA256SUMS before
considering a per-app Open Anyway exception. Do not disable Gatekeeper globally.
Ad-hoc updates can require a new Screen Recording grant.

Independent clean-machine acceptance remains not run; the user explicitly
accepted local validation for this release. Local lifecycle smoke suppresses Pet
capture/TCC prompts and is not permission or Pet acceptance evidence. Future
corrections require a new tag and build number; prior release assets are immutable.
