# Pet Halo 0.1.0 Beta 10

## Changes

- Hide the Halo when Codex quits. Cancel pending positioning and reject late
  images; a newly started Codex process receives one fresh positioning request.
- Add **Continuous Following** to the menu bar. It is off on every Pet Halo launch.
  Fixed mode only positions on startup, Codex relaunch or **Locate Pet**.
- Optional following processes one Pet-overlay image at a time, then waits one
  second before the next request. Switching it off cancels scheduled work and
  keeps the last successful position. This mode can consume more CPU and memory.
- No Usage semantics, ring thresholds or CLI compatibility policy changes.

## Privacy and permissions

Screen Recording remains required for local Pet positioning; Accessibility is not
required. Captures include only the selected Codex process's Pet overlay, which
can contain status or Quick Chat pixels. All pixels remain in memory: no OCR,
saved images, transmission, capture stream or mouse tracking. Fixed mode has no
positioning timer or repeated capture. The following toggle is session-only.

## Download and trust

`Pet-Halo-0.1.0-beta.10-unsigned-universal.zip` supports Apple silicon and Intel,
macOS 14 or later. This is an **Unsigned Developer Preview** with complete ad-hoc
bundle signatures and Hardened Runtime. It is not Developer ID-signed and is
not notarized by Apple. Gatekeeper may block launch. Verify the source, provenance
and checksums before applying any local developer-warning exception. Screen
Recording access may need to be granted again after an ad-hoc update.

Independent clean-machine acceptance is not run under the user's explicit Beta 10
local-validation exception. Local checks and public-download postflight are
recorded separately and do not establish Apple trust.
