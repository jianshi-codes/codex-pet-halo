# Pet Halo 0.1.0 Beta 11

## Changes

- Add a thin blue weekly reset-time arc immediately inside the Weekly quota ring.
  It shares the quota arc's start and direction and shows remaining time against
  a seven-day reference (604,800 seconds), using Codex's reported reset timestamp.
- Compare remaining fractions: a shorter quota arc than time arc means quota is
  being consumed faster than a uniform weekly pace. This is a reference, not a
  forecast or a change to Codex's reset policy.
- Schedule time-arc updates once per hour to minimize work. Usage refreshes can
  redraw it sooner. Clock-only display lag can be up to one hour.
- Hide the time arc when weekly reset data is missing or unavailable; fade and
  dash stale data. Clamp to 0–100% and stay empty after reset until a new timestamp
  arrives. Never infer a missing reset date.
- Refresh documentation and synthetic SwiftUI previews. The optional 5h quota
  ring, reserved Context slot, quota thresholds and CLI compatibility policy are
  unchanged.

## Privacy and permissions

This display uses existing in-memory weekly quota data and the local clock. It
adds no server request, capture, permission, persistence or telemetry. Default
fixed positioning and the optional default-off Continuous Following toggle are
unchanged. Screen Recording remains required for Pet positioning; an ad-hoc
upgrade may require removing and re-adding Pet Halo in Screen Recording settings.
