# Pet Halo 0.1.0 Beta 5

Pet Halo is an independent, unofficial macOS companion for Codex. Beta 5
hardens Pet discovery for the current Accessibility layout and restores the
latest accepted visual-center and Ring-direction behavior while preserving the
existing Usage presentation and fallback hierarchy.

## Highlights

- Accepts one unique visible non-standard Accessibility Dialog as a bounded Pet
  discovery fallback when the current layout no longer exposes a near-square
  Pet surface.
- Removes only a substantially containing wrapper when both compatibility
  candidates have unknown subroles; known SystemDialog/Dialog priority remains
  unchanged, and ties or persistent ambiguity still fail closed.
- Uses the latest manually accepted visual-center offset baseline of
  `(-25.5, -1.5)` points. Existing saved visual-center preferences remain
  intact, and Reset Visual Center returns to this baseline.
- Without an activity surface, the selected display's visible-frame midpoint
  places the visible Ring arc above a Pet in the upper half and below a Pet in
  the lower half.
- An active activity surface overrides that screen-half default and keeps the
  visible Ring on the side opposite the activity surface.
- Pet midpoint tracking, Ring geometry, Usage semantics, the Pet → calibrated
  window → free-floating fallback hierarchy, and the no-screenshot/no-OCR
  privacy boundary are unchanged.

## Compatibility boundary

The candidate preserves the existing exact `com.openai.codex` Accessibility
application boundary and reads only the role, subrole, visibility, position,
size, and lifecycle geometry required by Pet following. It does not inspect
window titles, conversation content, screenshots, or OCR. Exact reviewed and
provisional CLI/Desktop evidence remains in `docs/COMPATIBILITY.md`.

## Requirements

- macOS 14.0 or later on Apple silicon or Intel.
- Supported Codex CLI and Desktop versions listed in `docs/COMPATIBILITY.md`.
- Accessibility permission only when following is enabled.

## Distribution boundary

This is Beta software distributed as an **Unsigned Developer Preview**. The
manually gated GitHub workflow publishes it only from reviewed `main`, with the
new `v0.1.0-beta.5` tag and bundle build `5`, after the unsigned artifact,
manifest, release notes, checksums, and source commit pass validation.

`Pet-Halo-0.1.0-beta.5-unsigned-universal.zip` is not signed with a Developer ID
certificate and is not notarized by Apple. macOS may block its first launch.
Verify `SHA256SUMS`, the GitHub source, and repository provenance before deciding
whether to override Gatekeeper. A future signed/notarized artifact must use a
new tag and build number; it must not replace this release.
