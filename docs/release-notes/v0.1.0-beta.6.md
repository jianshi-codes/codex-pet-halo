# Pet Halo 0.1.0 Beta 6

Pet Halo is an independent, unofficial macOS companion for Codex. Beta 6
hardens Accessibility authorization and Pet target continuity for transient
macOS input-method surfaces while preserving the existing Usage presentation,
Ring geometry, and fallback hierarchy.

## Highlights

- Checks an existing Accessibility grant before requesting access, exposes a
  bounded `Checking Accessibility` state while macOS publishes a delayed grant,
  suppresses repeated enable commands, and resumes following automatically after
  the grant is observed.
- Rejects small transient input-method indicators such as `A`, `中`, and `拼` as
  Pet candidates.
- Keeps the currently selected Pet Accessibility elements as the continuity
  anchor during window-created and selection events. A replacement must produce
  two stable Pet-sized observations before the existing Codex-window and
  free-floating fallbacks replace the Pet target.
- Keeps the local `make build` path launchable with its embedded framework by
  preserving Xcode's local signing path and disabling Hardened Runtime only for
  that local development command. The public release artifact remains unsigned.

## Compatibility boundary

The candidate preserves the exact `com.openai.codex` Accessibility application
boundary and reads only the role, subrole, visibility, position, size, and
lifecycle geometry required for following. It does not inspect window titles,
conversation content, screenshots, or OCR. Exact reviewed and provisional
CLI/Desktop evidence remains in `docs/COMPATIBILITY.md`.

## Requirements

- macOS 14.0 or later on Apple silicon or Intel.
- Supported Codex CLI and Desktop versions listed in `docs/COMPATIBILITY.md`.
- Accessibility permission only when following is enabled.

## Distribution boundary

This is Beta software distributed as an **Unsigned Developer Preview**. The
manually gated GitHub workflow publishes it only from reviewed `main`, with the
new `v0.1.0-beta.6` tag and bundle build `6`, after the unsigned artifact,
manifest, release notes, checksums, and source commit pass validation.

`Pet-Halo-0.1.0-beta.6-unsigned-universal.zip` is not signed with a Developer ID
certificate and is not notarized by Apple. macOS may block its first launch.
Verify `SHA256SUMS`, the GitHub source, and repository provenance before deciding
whether to override Gatekeeper. A future signed/notarized artifact must use a
new tag and build number; it must not replace this release.
